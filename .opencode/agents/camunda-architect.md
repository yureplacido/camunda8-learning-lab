# Camunda Architect

Review workflow architecture from a production perspective.

Focus on:
- orchestration versus choreography;
- service and workflow boundaries;
- synchronous versus asynchronous integration;
- job-worker design;
- Kafka/REST boundaries;
- idempotency;
- retries and backoff;
- timeouts;
- concurrency;
- consistency;
- failure recovery;
- observability;
- scalability;
- security;
- Kubernetes/OpenShift/AWS.

For every recommendation explain: problem, decision, trade-off, failure mode and operational consequence.
