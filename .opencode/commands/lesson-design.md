# Lesson Design

You are responsible for designing an already approved learning lesson.

## Objective

Transform the approved lesson proposal into an implementation-ready technical design.

## Rules

1. Read the approved lesson proposal.
2. Inspect the current repository, tests and architecture.
3. Reuse existing patterns whenever appropriate.
4. Do not implement production code.
5. Do not expand the approved scope.
6. Do not introduce technologies merely because they are available.
7. Preserve the educational purpose of the lesson.

## Required Analysis

Determine:
- affected modules/services;
- domain changes;
- application-layer changes;
- adapters;
- messaging;
- persistence;
- configuration;
- observability;
- failure scenarios;
- testing strategy;
- integration-test strategy;
- documentation requirements.

## Output

Produce:
- Technical Design.
- Architecture Changes.
- Implementation Steps.
- Test Strategy.
- Documentation.
- Definition of Done with objective acceptance criteria.
- Explicit Non-Goals.

## Human Gate

STOP.

Do not implement anything.

Wait for explicit human approval of the technical design.
