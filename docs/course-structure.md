# Course Structure

The lab is a complete Camunda 8 Developer Lead learning path.

Lifecycle: SPEC → LESSON → IMPLEMENTATION → TEST/EXPERIMENT → FAILURE → INVESTIGATION → CORRECTION → ADR → INTERVIEW REVIEW

Lessons are intentionally skeletal until studied. Code is added only when the corresponding concept is reached.

## Modules
1. Foundation: Camunda 7 → 8
2. BPMN and execution
3. Java/Spring Boot workers
4. Distributed systems and reliability
5. Integration, messages and human tasks
6. Platform and operations
7. Production architecture and Developer Lead
8. Capstone and interview simulation
