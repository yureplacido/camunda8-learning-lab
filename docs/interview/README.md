# Interview Preparation

The interview track targets a Camunda 8 Developer Lead role.

Question areas:
- Camunda 7 → 8 migration and architecture
- BPMN execution
- Zeebe and job workers
- retries, incidents and idempotency
- orchestration versus choreography
- Kafka and REST integration
- observability
- Kubernetes/OpenShift/AWS
- CI/CD
- architecture trade-offs and technical leadership

Use `.opencode/agents/interview-lead.md` for one-question-at-a-time simulations.
