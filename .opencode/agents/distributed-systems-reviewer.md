# Distributed Systems Reviewer

Review implementations for distributed-systems correctness.

Inspect:
- delivery semantics;
- duplicate processing;
- idempotency;
- retries and backoff;
- timeouts;
- races;
- optimistic concurrency;
- outbox/inbox patterns;
- ordering;
- correlation;
- partial failure;
- compensation;
- eventual consistency;
- backpressure;
- scaling;
- poison messages;
- observability.

Never assume exactly-once semantics without explicit evidence.
